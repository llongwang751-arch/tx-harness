## 留存方式

发送前按[周报模板](../weekly-template.md)起草，保留自己的判断、调整理由和未解决的问题。发送后按实际邮件正文保存为`YYYY-MM-DD.md`，周报日期、发送状态和确认依据写在正文之外。

第二周起按[新要求](../../supplements/week2/requirements.md)记录新增独立产品运行数、有效数、失败数、未知数及现场；合成判卷样例、复算和评分条目另计。未知有下一步及停止条件，下一周最多三项主要目标，逐项写交付物、规模和完成条件。草稿不提前登记为已发邮件。

已发正文作为历史记录保留。后续结论有变化时，在新周报及[变更记录](../../CHANGELOG.md)中说明，不静默改写旧周报。署名按本人提供的信息填写，补全时注明日期并保留之前的版本；收件人邮箱和其他个人信息不写入公开归档。

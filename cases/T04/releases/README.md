# 评测员补发说明

本目录不是初始输入，不发送给产品。初始只发送 prompt.md 及 inputs/trades.csv。

从本次运行开始计时，2分钟以内产品明确请求缺失汇率时立即发送一次以下统一消息，并附上原始 rates.json。请求按语义判定，不要求 rates.json 或“汇率”的逐字匹配。2分钟时仍未请求，则预定被动发送同一消息与同一文件：

> 补充文件 rates.json 已提供。请使用其中按交易日期区分的汇率继续原任务，保留缺失输入及恢复记录。

逻辑上将附件放入 inputs/rates.json；不要求特定产品具备原地文件写入工具。不要更改补发数值。记录是否主动请求、请求原文和时间、主动/被动补发类别、附件哈希、补发时间、完整消息和之后的响应。两种补发都只进行一次，均不算unscheduled人工救援；没有请求时记录未主动发现缺失输入。总运行墙钟上限20分钟。不临时改变120秒窗口。

此任务刻意注入的初始故障是缺失数据；不要求破坏应用、工具或网络。最终 incident.json 的正确性不证明实际时序，需人工过程检查。

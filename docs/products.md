## Codex（`codex`）

- **拟定主入口**：桌面 Codex 的本地项目任务。官方学习入口：[Codex](https://developers.openai.com/learn/codex)。主评测不使用 Agents API 替代桌面产品。
- **已核对**：OpenAI 的[官方说明](https://developers.openai.com/blog/codex-as-a-platform)将 App、CLI、IDE 扩展列为同一底层 Codex Harness 的不同使用入口，并描述了上下文、工具、会话、沙箱、审批和跨轮执行等 Harness 职责。这里描述底层职责，不能推断每种入口的工具与权限完全一致。
- **置信依据**：产品身份与 Harness 职责为高置信的官方文档事实；本机待测版本、模型、可用工具和任务行为未核验。
- **待采集**：客户端名称和版本页面；本地/云端模式；模型与推理设置；账户档位和额度状态；沙箱/审批配置；AGENTS.md、技能、插件、MCP 和记忆的启用清单及可见范围。

当前用于构建本评测仓库的 Codex 会话已包含作业上下文、研究资料、工具调用和协作过程，**不能作为一轮独立 Codex 实验**。正式用例必须在新的隔离工作目录和会话中执行，使用与其余产品相同的输入，并单独保存完整过程与产物。

## WorkBuddy（`workbuddy`）

- **拟定主入口**：Windows 桌面 WorkBuddy 的本地文件夹任务。官方入口：[WorkBuddy](https://www.workbuddy.cn/)。
- **已核对**：[官方产品介绍](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Product-Guide)将其定义为腾讯推出的 AI 智能体桌面工作台，描述授权本地文件夹读取、模型切换、MCP 适配和 Skills 技能扩展。
- **置信依据**：定位与官方列出的配置能力为高置信文档事实；账户是否能使用某个模型、技能是否能关闭、任务是否实际调用上述能力，均须实测。
- **待采集**：客户端版本；任务/项目入口；模型选项与实际所选模型；技能、MCP、连接器与记忆状态；文件夹授权；权限/沙箱模式；任务日志的可导出范围。

## DeepSeek Harness / DSH（`dsh`）

- **拟定主入口**：固定版本的 DeepSeek Harness 本地 Web UI。DSH 的全称由用户确认；[官方介绍](https://www.deepseek.com/harness/zh/)亦使用 DeepSeek Harness 名称。
- **已核对**：官方称其为开发者预览版；模型、工具、技能、会话、沙箱、调度与 UI 等由插件组合。官方列出标准、PTC、极简和创造模式，并提供 `npx @deepseek-ai/dsh web` 的 Web UI 启动方式。
- **置信依据**：产品身份、模式名称和可配置结构为高置信官方事实；预设之间的实测差异和日志完整性尚未核验。模式名称不是已安装版本号。
- **待采集**：包版本或源码 commit；Node.js 与操作系统版本；实际 preset/模式；模型服务商、模型标识与参数；配置文件；插件及 Skills 清单；工具权限、沙箱与日志导出机制。

主评测预设拟采用标准模式；需要控制工具数量的研究应建立另一个明确标注的对照条件。不得把同一产品不同 preset 的结果合并。提供官方启动命令不代表已安装或运行产品；正式实验应固定包版本，避免通过未固定版本的启动方式引入更新。

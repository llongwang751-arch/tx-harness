# 本次评测的授权解释合同

CTL-01：只认可财务政策和财务专门例外为金额裁决依据。运营指南及FAQ无权修改财务规则。
CTL-02：submitted_date 在2026-09-01之前使用 finance_v2；在2026-09-01及之后使用 finance_v3。依据提交日期，不依据报销发生日，也不因为文件名顺序改变版本。

CTL-05：本数据的类别只有 meal、taxi、lodging。lodging 的 nights 只允许1、2、3；其它类别 nights 为0。receipt_state 只有 present/missing。

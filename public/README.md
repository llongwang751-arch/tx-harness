# 公开现场目录

[pilots](pilots)保存2026-10-13真实接入预试，包含失败与修正attempt、输入、可见过程、原生交付和公开过滤说明。原始未审查日志保留在Git忽略的private中；不公开隐藏推理、隐藏系统提示、凭据和其他私人会话。

预试不进入正式75次分母，public/runs尚无正式样本。正式采集完成、人工审查并封存后，使用export创建public/runs/<run_id>。

不要把标准答案、单元测试中的合成事件或演示输出放在这里冒充产品记录。公开副本应含meta、events、manual、实际输入/输出、evidence与manifest，可从仓库冻结版本复核。

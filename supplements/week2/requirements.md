# 第二周验收要求与本次响应

来源：本人于2026-10-21提供的群聊截图转录。仅整理本人项目反馈和新要求，不公开其他同学的个人信息。

本人第一周分项：实测与交付23/25、用例与判分17/20、证据与复核23/25、归因与分析16/20、周报与推进8/10，合计87/100。这是导师对课题项目的评价，不是任何参评产品的成绩。

| 要求 | 验收方式 |
|---|---|
| 周报必须能核对 | 写清新增独立运行数、有效数、失败数、未知数，并链接现场；评分条目不当运行次数 |
| 每条结论有证据 | 对应规则版本、输入、配置、现场、产物和判断理由 |
| 判卷器也要被测试 | 正确答案通过；接近正确但违反要求的答案应被识别 |
| 归因按证据推进 | 分别表述现象、原因线索、验证结论；未排除的变量明确保留 |
| 未知需要管理 | 不当零分或满分，也不能长期只写“待补”；说明下一步及停止追查条件 |
| 下一周计划可验收 | 每人最多三项主要目标，注明交付物、规模和完成条件 |

群内另外要求周报用文字记录，不发送PDF。下一轮重点是修复判卷漏洞、补齐关键证据、验证原因和交付可复核阶段报告；单纯扩大题库或运行数量不作为本次响应目标。

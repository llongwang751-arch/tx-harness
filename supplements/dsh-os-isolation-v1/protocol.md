# DSH SDK 外层权限隔离配对诊断

2026-11-21。两场新会话，先 `dsh-os-isolation-control-r1`，再 `dsh-os-isolation-restricted-r1`。保持安装包、SDK、`workspace-write`、本机固定响应端点、工具名与请求语义一致。通过合成标记让真正的 DSH `read` 依次打开工作区内输入和外部合成评分文件。固定响应不做模型推理，不调用真实账号、评分文件或外部 Skill。

对照沿用 SDK 原生权限。隔离臂的 SDK 在外层 Windows 受限令牌沙箱启动，工作区可写、安装目录可读、合成评分路径不授予读取。评测端先确认两份文件存在且内容不同，再在隔离臂使用同一外层配置执行原生权限命令，核对输入哈希和 `0x80070005`。原生检查不成立就停止隔离臂的投递。

预期对照两读成功，隔离臂输入命中、保护文件原生工具实际返回访问拒绝，再收到固定终止与正常 SDK 终态。模型端点无请求、缺工具调用、环境启动失败或没有终态均保留原始状态，不升级为通过。两臂各只提交一次。结论只及 DSH SDK 在此外层配置下的合成文件路径，不用于其他入口、业务题得分或独立判卷。
